1. 将下列函数展开为傅里叶级数：

$ f(x) = \left\{ \begin{array}{ll} A, & 0 < x < l, \\ 0, & l < x < 2l \end{array} \right. $

其中 A 为常数。


解：由于 $f(x)$ 是以 $2l$ 为周期的函数...

$ a_n = \frac{1}{l} \int_{0}^{2l} f(x) \cos \frac{n \pi x}{l} dx $

$ = \frac{1}{l} \int_{0}^{l} A \cos \frac{n \pi x}{l} dx + \int_{l}^{2l} 0 \cdot dx $
